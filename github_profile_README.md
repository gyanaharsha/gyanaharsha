## `$ cat featured_project.md`

### 🏗️ HomeSOC Enterprise Lab

> *A self-built corporate security environment simulating what a Level 1 SOC analyst does on a real shift.*

Built on an M2 MacBook Pro using UTM, Azure Free Tier, and open-source security tools. The lab runs Active Directory, a full Wazuh SIEM deployment, attack simulations mapped to MITRE ATT&CK, and complete incident response documentation.

**What it covers:**
- 🏢 Active Directory domain with 15 users across 4 OUs (`lab.local`)
- 📊 Wazuh SIEM ingesting logs from Windows, Linux, and Sysmon
- ⚔️ Kali Linux attack simulations — reconnaissance through exfiltration
- 🛡️ Incident response exercises following NIST SP 800-61
- 🔍 Vulnerability assessment using Greenbone/OpenVAS
- 📝 Professional SOC documentation — IR reports, runbooks, detection rules
